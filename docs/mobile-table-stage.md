# Step 6.5 全屏移动牌桌

## 范围

牌桌是单一视口舞台：`100dvh`、页面本身不滚动、Hero 固定底部、公共牌和底池固定居中。2–9 人使用离散模板，不绘制明显圆形或椭圆桌体。服务端 `seatIndex` 不因视觉旋转而改变；前端只把当前用户旋转到视觉底部。

顶部左侧是房间菜单，右侧是历史、邀请 `+`、音效和购物车。左侧排名/聊天半透明入口可纵向拖动并持久化位置；历史只使用顶部按钮，不再放置右侧悬浮入口。抽屉互斥且都支持向外侧滑关闭，也可点击仍露出的桌面背景关闭。中央等待态提供与 `+` 完全等价的邀请复制；复制内容只含产品名、房间名、房间码和可选口令提示，不含密码、手机号或 Session。

Hero 区把本人头像放在中间、两张底牌放在右侧，并持续显示当前牌型、stack 和连接状态。其他玩家使用头像颜色/灰度/黑色“站”区分参与、弃牌和站起；本街最新的跟注、过牌、下注、加注、弃牌或全下会临时替换昵称，到下一街或手牌结束后清除。本街投入（包括全下）以独立筹码和数字显示，不再叠加“行动中”文字。正在当前手内站起的玩家保持两张牌背并由服务器持续执行 `Check else Fold`。行动区只渲染服务端 legal actions，显示当前下注、Call 金额、快捷加注和服务器 deadline；围观者不渲染行动或预操作区。点击 `1/3 Pot`、`1/2 Pot`、`2/3 Pot`、`Pot`、`1.2 Pot` 或 `All-in` 会立即提交对应合法 Bet/Raise，不再打开确认层；主“下注/加注至”按钮仍打开竖向 slider overlay供精确金额确认。所有金额为安全整数并 clamp 到 min/max；Raise 表示 Raise To。

房间中央显示服务器房间剩余时间，不再正向累计运行时间。创建页以分档滑条选择 30–180 分钟房间时长和 10–45 秒行动时间。当前行动者最后 3 秒在不遮挡牌面/行动区的位置显示脉冲倒计时与“加时”按钮；按钮不确认，余额不足时禁用且不弹错误。

进入或加入房间直接到全屏牌桌的站起围观状态；旧 `/rooms/:roomId` 作兼容重定向。未入座时 Hero 区完全留空，不显示“点击空座/恢复后手”说明框。首次点击空座领取房间 Initial Buy-in，之后点击空座恢复该房间保留后手，不弹首次带入表单且不扣钻石；购物车直接打开补充后手托条，坐下或站起均可使用，托条固定 10 档、默认最大档且单次上限为 Initial Buy-in。结算后 Stack 为 0 自动站起，可先补点再重新坐下。

左抽屉默认展示本桌排名：按盈亏降序，正数红、负数绿、零值中性；离桌玩家可切换并用半透明灰度区分。每行只显示入池率、胜率、本局总带入和盈亏；玩家列表独立滚动，公共桌况固定在底部，不显示活跃度积分。聊天页提供最近 50 条临时消息、固定底部输入区和原生 Emoji 快捷键；单条最多 120 个可见字符。已入座玩家的新消息根据座位靠近屏幕边缘的方向显示头像气泡，每段最多 24 个可见字符，1.8 秒后用下一段替换，最后一段显示 3 秒后消失；气泡不滚动也不接收指针事件。右侧历史详情的玩家/行动区域独立滚动，公共牌、翻页、偷偷看和发发看固定在抽屉下部。房间内的参与者与围观者都可查看公共历史并使用自己的偷偷看/发发看授权。钻石看牌与发发看只在历史抽屉/历史详情出现。

## 完整但非最终美术

本阶段没有最终品牌美术要求，但等待、进行、断线、Review、暂离、输光、关闭等状态均需可理解且可操作。卡牌、筹码、桌面、聊天气泡和赢家反馈由项目原创 HTML/CSS/SVG/Web Audio 生成；项目所有者提供的 WAV 用于男/女行动语音及坐下/站起。AudioContext 在首次真实指针、触摸或键盘手势中解锁；左上角菜单可切换男/女声，默认男声。钻石购买和桌面皮肤入口已删除；保险保持禁用占位；普通模式的“发两次”已成为真实功能，使用双排紧凑公共牌、5 秒协商和逐副结果反馈；“精彩对局”占位已删除。聊天使用文字和 Unicode Emoji；语音聊天继续永久禁止。

## 隐私和可访问性

隐藏底牌组件不接收牌码；牌码不能出现在隐藏节点、DOM 属性、aria、日志或 storage。active hand 中本人两张牌可分别点击切换待亮：未选牌保持普通牌面，已选牌只使用暖色与小型半透明 Eye，不显示“待亮”文字；进入 Review 后，非强制摊牌玩家仍可逐张添加或撤回展示，已展示牌移动到头像位置，下一手清空。触控目标至少 44px，支持 safe-area 与 375×812、390×844、430×932。`prefers-reduced-motion` 会关闭发牌/公共牌运动和脉冲，不改变 deadline、音效开关或状态推进。认证页密码输入提供独立的“显示密码/隐藏密码”眼睛按钮。牌面 rank `T` 在 UI 统一显示为紧凑的 `10`，内部牌码仍保持 `T`。

牌桌打开时会请求浏览器 Screen Wake Lock，并在页面从后台返回时重新获取。生产 HTTPS/PWA 且浏览器支持时可显著降低息屏；普通 LAN HTTP、系统强制省电或浏览器不支持时无法保证，失败不会阻断牌局。
