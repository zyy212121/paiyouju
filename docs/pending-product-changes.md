# 待实现产品变更

本文件只记录尚未获准实施的产品调整。这里的内容不代表当前代码行为、正式规格或测试基线已经改变。

## 2026-08-28 房间时长的起算与连续性

状态：已于 2026-08-28 获准实现。

- 房间未正式开始前，不启动房间时长倒计时。
- 房间一旦正式开始，倒计时按连续时间运行，不暂停、不重置。
- 停发、玩家退出、站起、保位离桌、人数不足等情况均不影响已经开始的倒计时。
- 到期后的牌局收尾与房间关闭行为，实施时继续遵守“不中断当前手，当前手完成后停发并关闭”的规则。

实施结果：首次正式开始时写入唯一 `tableStartedAt` 与 `expiresAt`；后续人工重启发牌只沿用原截止时间。首次开始前不调度到期任务，界面显示“未开始”。

## 2026-08-28 坐下与站起公共音效

状态：公共播放逻辑已确认；并发逐事件重叠播放尚未实现或验收。

- 任意玩家在房间内坐下或站起时，房间内的其他玩家都应听到对应音效。
- 坐下与站起音效属于公共事件音效，不只对动作发起者本人播放。
- 多名玩家短时间内同时或连续坐下、站起时，允许多个音效并行、重叠播放，不应由后一个音效中断前一个音效。

收到明确修改指令前，不调整音效代码、实时事件、测试或正式规格。

确认记录：当前实现会根据房间座位名单变化向所有客户端播放坐下或站起公共音效，不限定为动作本人。若一次状态更新同时包含多名玩家变化，当前只触发一次对应音效；“每个并发动作各自重叠播放”尚未单独实现或验收。
