## 文字需求记录

1. 快捷加注必须显示明确金额并在点击后立即提交；只有主“下注/加注至”按钮进入精确金额确认流程。
2. 首次点击空座领取房间 Initial Buy-in；站起、退出或重连后再次坐下恢复原后手，不重复领取、不扣 Wallet 钻石。桌上点数归零后自动站起并可重坐补点。
3. 左右抽屉支持向外侧滑关闭。
4. 积分看牌和发发看只出现在历史牌局，不在结算画面增加入口。
5. 每手保存唯一的完整五张公共牌候选；普通历史只公开真实发出的 Board，触发发发看后持久公开隐藏部分，同一手所有人和所有页面切换看到同一结果。
6. 左侧排名/聊天半透明入口可沿屏幕纵向拖动；历史已有顶部按钮，后续需求已删除右侧悬浮历史入口。
7. 左侧抽屉增加本桌排名：按盈亏降序；正数红色、负数绿色、零值中性；可显示/隐藏离桌玩家，离桌行使用半透明灰度；不显示活跃度积分；底部显示公共桌况。

## 完成状态

上述 5 项图片问题与 7 项文字需求均已实现，并按后续要求移除右侧悬浮历史入口与“精彩对局”占位。房间点数独立记账、唯一 `fullBoard`/发发看、排行榜聚合使用服务器集成测试；快捷加注、牌面、抽屉侧滑、左入口拖动、文案与历史结果恢复使用 Web 组件测试；最新规则由 PostgreSQL Accounting/Realtime/Recovery 回归覆盖首次 Initial Buy-in、站起保存后手和再次坐下恢复同一 GameSession。
